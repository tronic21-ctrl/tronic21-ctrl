### Featured Project: BanSOSChain

*A public audit trail for social aid disbursement in Indonesia.*

**[Live Dashboard](https://bansoschain.vercel.app)** · **[Repo](https://github.com/tronic21-ctrl/bansoschain)** · **[Demo Video](VIDEO_LINK)**

![Tests](https://img.shields.io/badge/tests-22%20passing-38bdf8?style=flat-square&labelColor=060d1a)
![Coverage](https://img.shields.io/badge/contract%20coverage-100%25-38bdf8?style=flat-square&labelColor=060d1a)
![Contracts](https://img.shields.io/badge/contracts-2%20verified%20on%20BscScan-f0b90b?style=flat-square&labelColor=060d1a)
![Hackathon](https://img.shields.io/badge/Indonesia%20Web3%20Hackathon%202026-submitted-818cf8?style=flat-square&labelColor=060d1a)

```mermaid
flowchart LR
    A[Submitted] --> B[AI review]
    B --> C[Approved]
    C --> D[24h objection window]
    D --> E[Disbursed]
```

- Every step, from application to disbursement, is recorded on-chain and can be checked by anyone
- Ponder indexer feeding a bilingual (EN/ID) dashboard with BscScan links for each step
- AI-assisted eligibility check with human verifier review
- Recipient names are masked, and recipients are identified on-chain by an ID Hash

| Contract | Network | Verified on BscScan |
|---|---|---|
| BeneficiaryRegistry | BNB Chain Testnet | [REGISTRY_ADDRESS](https://testnet.bscscan.com/address/REGISTRY_ADDRESS#code) |
| DisbursementPool | BNB Chain Testnet | [POOL_ADDRESS](https://testnet.bscscan.com/address/POOL_ADDRESS#code) |
